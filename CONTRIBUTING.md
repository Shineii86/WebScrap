# Contributing to WebScrap

Thank you for your interest in contributing! Here's how to get started.

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/WebScrap.git`
3. **Create** a branch: `git checkout -b feature/your-feature`
4. **Make** your changes
5. **Test** in Google Colab
6. **Commit**: `git commit -m "Add your feature"`
7. **Push**: `git push origin feature/your-feature`
8. **Open** a Pull Request

## Guidelines

- Test all changes in Google Colab before submitting
- Keep the notebook cells simple and well-commented
- Follow the existing code style
- Update CHANGELOG.md with your changes
- One feature per PR

## Reporting Issues

Use the [issue templates](.github/ISSUE_TEMPLATE/) to report bugs or request features.

## Code of Conduct

Be respectful and constructive. We're all here to learn.
